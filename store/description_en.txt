◆Introduction

We are conducting an experiment to fundamentally rethink browser operation, without relying on AI or other technologies, and completing the process entirely locally.

Have you ever experienced any of the following?

・Using the mouse to operate the browser is cumbersome.

・You keep many tabs open because you feel anxious about not being able to see things immediately if they're not open.

・Even with many tabs open, finding what you're looking for and managing them is difficult.

The author has always felt dissatisfied with these points during their work, and more precisely, decided to realize their desire for "efficient browsing from a perspective other than tabs!"

◆Development Methodology

Fortunately, in this age where "coding is easy" thanks to AI, all code generation is done by AI, and development is being carried out through rapid trial and error.

However, the most important thing we prioritize is the following:

1) The extension must operate entirely locally.
We strictly adhere to using only libraries, including external LLMs (AI) via APIs, etc., that are always contained within packages.

2) No AI Used
You might be thinking, "But it's made with AI!", and that's a valid point. However, as mentioned in the "◆Introduction," we are committed to "not using LLM for the extension's operation."
The programs included in the extension operate and process data purely mechanically, and we strive for high precision and completeness as a "tool" by correcting any bugs.

◆About the Developer

This extension is currently being developed by one person.
They always maintain strong guidelines, specifications, and their own aesthetics, and do not engage in development that relies solely on AI. However, it is also true that they have concerns about using unfamiliar languages and frameworks with the help of AI.

For this reason, this extension is a "demo," and while it is free to use, please understand that it may always contain some bugs, and use it at your own risk.

We would also appreciate any feedback you may have after trying it out. Please send it to the address below.

◆Commands

| Command | Description |
|----------|------|
| `help` / `?` | Show help |
| `aboutbmxt` | Open the BMXt welcome page in a new browser tab |
| `clear` | Clear logs |
| `exit` | Close the active terminal session; when it is the last session, close the BMXt window and clear process-scoped state |
| `tab` | Show available options, then restore the prompt to `tab ` (with a trailing space) for continued input |
| `tab -list [-url]` | List open tabs as plain tree (IDs included); `-url` adds URLs |
| `tab -list [-url] | browse` | Open tab picker column; search, multi-select `#`, bulk modes; `/` searches titles, Enter highlights, `n` jumps matches |
| `tab -exit -list` | Close tab picker column in this session (including `group new` picker) |
| `tab -setting -page-active --auto \| --manual` | Tab picker: toggle whether moving the highlight auto-activates the tab (`--auto` default; `--manual` uses Alt+↑↓); saved setting |
| `tab -moveurl <url>` | Focus a tab with the given URL or open a new tab (http/https) |
| `tab -nowurl` | Show the current tab’s URL |
| `tab help` | Show the `tab` manual section |
| `back` | History back on the target active tab. Batch: `tab -list \| back` |
| `forward` | History forward on the target active tab. Batch: `tab -list \| forward` |
| `reload` | Reload the target active tab. Batch: `tab -list \| reload` |
| `close` / `c` | Close the target tab after y/n confirm; `close <tabId>` / `c <tabId>` closes that id without confirm. Batch: `tab -list \| close` |
| `dom` | Print available options; Enter alone restores the prompt to `dom ` (trailing space) for the next token |
| `dom -list [--normal\|--with] [--html\|--react] [--tag] [<pattern>]` | Plain DOM list from active tab (default `--normal --html`); optional substring filter; scriptable http(s) only |
| `dom -list … | browse` | Read-only DOM picker column; `--normal`/`--with`, `--html`/`--react`; may prompt for optional site access |
| `dom -exit -list` | Close DOM list picker column in this session |
| `nav` | Print usage; Enter alone restores the prompt to `nav ` (trailing space) for `-enter`, `-exit`, or `-windowclose` |
| `nav -enter` | Arm nav mode; **Alt** toggles the virtual cursor overlay on the target tab; arrows move; **Enter** click/type; **Ctrl** opens a context menu (text selection, save image, etc.); **/** incremental attribute jump; identity label `kind:key` |
| `nav -exit` | Fully disarm nav (turn the overlay **OFF** with **Alt** first) |
| `nav -windowclose` | Close the window that contains the target tab after y/n confirm (never the BMXt window) |
| `search` | Print available options; Enter alone restores the prompt to `search ` for `-list` |
| `search -list [--all\|--history\|--bookmark\|--page\|--snapshot] [<pattern>]` | Plain search hit list (default scopes = `--all`). Case-insensitive substring (no regex in v1) |
| `search -list … | browse` | Search picker column; in-picker progress; detail view and `[history]` open-target tree |
| `search -exit -list` | Close the search list picker column (cancels an in-flight search if running) |
| `group new` / `group new <tabId> …` | Create a tab group — interactive tab picker when no tab ids, or non-interactive with explicit ids |
| `setting` | Print usage and restore the prompt to `setting ` for `-list` |
| `setting -list` | Plain list of current UI settings |
| `setting -list | browse` | Open settings picker column; commit with `> save setting` |
| `snapshot -save [<tabId>]` | Save the active tab (or given tab) as a Markdown snapshot with YAML frontmatter (Obsidian-compatible); storage destination follows setting snapshot storage |
| `setting -exit -list` | Close the settings picker column in this session |
| `session` | Print usage and restore the prompt to `session ` for second tokens (tmux-style terminal sessions in one BMXt window) |
| `session -new [name]` | Create a new terminal session and switch to it; optional display name |
| `session -list` | Plain list of terminal sessions |
| `session -list | browse` | Inline session picker on the prompt (↑↓ · Enter / 1–9) |
| `session -switch [name]` | Inline session picker by display name (type to filter · Enter inserts `session -switch <name>` · Enter again runs switch) |
| `session -next` / `session -prev` | Cycle the active terminal session |
| `session -setting-name [name]` | Rename the current session |
| `session <n>` | Switch to terminal session number n (1-based) |
| `translate` | Print usage and restore the prompt to `translate ` for `-on`, `-off`, or `-setting` |
| `translate -on` | Enable translation assist (nav typing preview under the prompt) |
| `translate -off` | Disable translation assist |
| `translate -setting --ja-en` / `--en-ja` | Save the translation pair for nav typing assist |
| `notes` | Show release notes for the current extension version; `notes <version>` for a specific version (e.g. `0.1.1`); `notes --list` lists versions that have entries |
| `<list-command> | browse` | Open a list as a picker column / inline UI (e.g. `tab -list | browse`); plain `-list` prints to the log |

Shortcuts (chrome://extensions/shortcuts): `launch-bmxt` (default Shift+Alt+C), `reset-bmxt` (default Shift+Alt+R), `toggle-bmxt-float` (default Shift+Alt+F — in-page float prompt on the active http(s) tab).
